Manual de uso - Cadastro de Livros

1. Para que serve

O programa cadastra os livros da biblioteca em um banco de dados MySQL. Para cada livro sao registrados o nome, o autor, a quantidade de paginas e o numero de copias.

2. Cadastrar um livro

  1. Preencha os quatro campos da tela.
  2. Clique em Cadastrar.
  3. Se tudo estiver correto, aparece a mensagem de confirmacao com o total de livros cadastrados, e os campos sao limpos.

3. Outras opcoes

  • Limpar (ou Arquivo > Limpar campos): esvazia todos os campos.
  • Fechar (ou Arquivo > Sair): encerra o programa.
  • Ajuda > Sobre: mostra os autores e a versao.

4. Mensagens de erro

MensagemO que fazer
Preencha o nome do livro.Digite o nome no primeiro campo.
Preencha o nome do autor.Digite o autor.
As paginas devem ser um numero inteiro valido.Use apenas digitos, sem letras nem virgula.
Copias deve ser maior que 0.Informe pelo menos 1 copia.

5. Atalhos de teclado

  • F1 - abre este manual
  • Ctrl+L - limpar campos
  • Ctrl+Q - sair

6. Requisitos

  • Java 8 ou superior;
  • MySQL em execucao, com o banco biblioteca.
