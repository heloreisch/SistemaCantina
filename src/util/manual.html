Manual de uso - Gerenciamento de Pedidos e Produtos

1. Para que serve

O programa cadastra tanto produtos quanto pedidos da cantina do IFSC em um banco de dados MySQL. Para cada produto sao registrados o nome, o preço, categoria. Enquanto para cada pedido são registrados Status do pedido,tipo de pagamento, o preço total do pedido,

2. Cadastrar um produto

  1. Clique em Novo.
  2. Preencha os três campos da tela.
  3. Se tudo estiver correto, o produto aparecerá na tela juntamente com os outros produtos cadastrados, e os campos sao limpos.

2. Cadastrar um pedido

  1. Clique em Novo.
  2. Escolha os produtos do pedido.
  3. Preencha os três campos restantes da tela.
  4. Se tudo estiver correto, o pedido aparecerá na tela juntamente com os outros pedidos cadastrados, e os campos sao limpos.

3. Outras opcoes

  • Limpar (ou Arquivo > Limpar campos): esvazia todos os campos.
  • Fechar (ou Arquivo > Sair): encerra o programa.
  • Ajuda > Sobre: mostra os autores e a versao.

4. Mensagens de erro

>
MensagemO que fazer
Adicione pelo menos um produto ao pedido.Escolha um produto e adicione no pedido.
O preço total deve ser um numero válido.Preencha um numero válido para o preço total ex: 12,50.

5. Atalhos de teclado

  • F1 - abre este manual
  • Ctrl+L - limpar campos
  • Ctrl+Q - sair

6. Requisitos

  • Java 8 ou superior;
  • MySQL em execucao, com o banco biblioteca.
